# TRACTATUS LOGICO-INFORMATICUS

## Логико-Информационный Трактат

---

> *О чём невозможно собрать данные, о том следует молчать.*

---

## ПРЕДИСЛОВИЕ

Трактат строится по строгой схеме:

1. **Данные** — фундаментальная ткань. Различаются по источнику: реальные, синтетические, метаданные.
2. **Информация** — данные в трёх режимах существования: хранение, обработка, передача.
3. **Знание** — модель, построенная из информации. Имеет три аспекта: модель мира, понимание, генерация.
4. **Интеллект** — цикл, замыкающий данные, информацию и знание в самоподдерживающийся процесс.
5. **Внимание** — единственная точка свободы внутри цикла.
6. **Субъект и сознание** — следствия интеграции цикла.
7. **Предел** — то, о чём нужно молчать.

Каждая пропозиция несёт нагрузку. Каждая пропозиция зависит от предыдущих. Декорация устранена. Иллюстративные апелляции к авторитетам вынесены в отдельную работу — Историческую Справку.

Возражения вводятся знаком **⊥** и рассматриваются по существу, а не отбрасываются.

— *Май 2026*

# 1. О ДАННЫХ

## 1.0 Что такое данное

**1** Есть данные.

**1.01** Данное есть зарегистрированное различие.

**1.02** Различие есть состояние двух частей мира, при котором они не тождественны по какому-либо параметру.

**1.03** Регистрация есть устойчивое сохранение различия в носителе.

**1.04** Различие без регистрации физически возможно, но не есть данное.

**1.05** Носитель есть часть мира, состояние которой меняется в зависимости от регистрируемого различия и сохраняет это изменение во времени, превышающем время изменения источника.

**1.06** Данное определено через три места:
- *Источник* — часть мира, изменения которой порождают различие.
- *Носитель* — часть мира, в которой различие сохраняется.
- *Адресат* — часть мира, в которой различие будет считано.

**1.07** Без всех трёх мест данное не реализовано.

**1.08** Атом данного есть бит: регистрация различия между двумя возможными состояниями.

**1.09** N-битное данное есть конъюнкция N независимых битов.

## 1.1 Континуум и дискретность

**1.10** Различие может быть градуальным.

**1.11** Регистрация градуального различия с конечной точностью даёт конечное число битов.

**1.12** Поэтому всякое реально регистрируемое данное конечно по информационному объёму.

**1.13** «Континуальные данные» суть данные с разрешением, превышающим возможности их различения; они дискретны по факту регистрации.

## 1.2 Классификация данных по источнику

**1.20** Данные классифицируются строго по источнику.

**1.21** Источник может быть вне системы — *реальные данные*.

**1.22** Источник может быть внутри системы — *синтетические данные*.

**1.23** Источник может быть структурой других данных — *метаданные*.

**1.24** Эти три класса исчерпывают онтологическое многообразие данных в рамках данной системы.

**1.25** Граница между внешним и внутренним проводится не натуралистически, а функционально: внешним для системы является то, что не находится под её прямым операционным контролем.

## 1.3 Реальные данные

**1.30** Реальные данные суть данные, источник которых не подчинён операционному контролю регистрирующей системы.

**1.31** Базовые модальности реальных данных в современной архитектуре:

**1.311** *Audio в AR (Augmented Reality)*: звуковой поток среды, регистрируемый и обогащаемый информационным слоем без вытеснения исходного.

**1.312** *Video в MR (Mixed Reality)*: визуальный поток, в котором реальные и синтетические объекты совместно существуют в единой сцене.

**1.313** *Inner в 3D*: внутренние сигналы системы (положение, ориентация, физиологическое состояние), представленные в пространственной форме.

**1.32** Реальные данные характеризуются:
- независимостью источника от системы;
- ограниченной пропускной способностью сенсоров;
- неустранимым шумом канала.

**1.33** Реальные данные служат критерием истинности модели: модель проверяется столкновением с потоком, который она не порождает.

## 1.4 Синтетические данные

**1.40** Синтетические данные суть данные, источник которых находится внутри системы.

**1.41** Три источника синтетических данных:

**1.411** *Обучение с подкреплением из среды*. Система действует в среде, среда отвечает, отклик регистрируется как новое данное. Источник — взаимодействие системы со средой; данное синтетично, поскольку без действия системы оно не существовало бы.

**1.412** *Когнитивная система*. Внутренние операции (рассуждение, имитация, моделирование возможных миров) порождают новые данные о возможностях. Источник — собственные процессы системы.

**1.413** *Личность*. Устойчивая саморепрезентация системы порождает данные о самой себе.

**1.42** Личность есть структура: *identity = persona + time*.

**1.421** *Persona* — текущая конфигурация саморепрезентации в данном контексте.

**1.422** *Time* — последовательность личностных состояний, удерживаемая как одна идентичность.

**1.423** Persona может быть множественной (роли, маски, контексты); time связывает их.

**1.424** Без time personas распадаются на независимые сущности; без persona time не имеет содержания.

**1.43** Личность различается по двум осям.

**1.431** Ось *human / not human*: степень соответствия профилю свойств, характеризующих биологического человека (телесность, эмоциональная регуляция, социальный модус).

**1.432** Ось *self / not self*: часть саморепрезентации, отождествлённая как агент управления (self), и часть, отождествлённая как объект управления или среда (not self).

**1.433** Эти оси независимы. Возможны: human-self, human-not-self (диссоциация), not-human-self (ИИ-агент с self), not-human-not-self (ИИ без самомоделирования).

**1.44** Синтетические данные онтологически равноправны реальным.

**1.45** Различие реальных и синтетических данных функционально, а не субстанциально: оба класса суть зарегистрированные различия в носителях.

**1.46** Подкласс «обучение с подкреплением из среды» имеет структуру:

**1.461** Действие a — выход системы.

**1.462** Состояние среды s — внешний контекст.

**1.463** Вознаграждение r — оценочный сигнал.

**1.464** Тройка (s, a, r) есть синтетическое данное опыта.

**1.465** Накопление троек строит модель политики π: s → a.

**1.466** Это базовая архитектура обучения через взаимодействие; она применима к биологическим и искусственным системам.

**1.47** Подкласс «когнитивная система» включает:

**1.471** *Воображение* — генерация возможных состояний среды без их непосредственного наблюдения.

**1.472** *Рассуждение* — преобразование одних утверждений в другие по правилам логики или вероятности.

**1.473** *Планирование* — построение последовательностей действий, ведущих к целевым состояниям.

**1.474** *Рефлексия* — обращение внимания на собственные процессы.

**1.475** Все эти операции порождают синтетические данные, которые не приходили из среды, но возникли внутри системы.

**1.48** Подкласс «личность» развёрнут в 1.42-1.433.

**1.481** Личность отличается от других синтетических данных тем, что она есть устойчивая структура, переживающая отдельные акты.

**1.482** Persona есть локальная конфигурация: способ проявления в данном контексте.

**1.483** Time есть глобальная структура: последовательность персон, удерживаемых как одна идентичность.

**1.484** Self есть та часть саморепрезентации, которой система приписывает агентность.

**1.485** Различение human / not human есть классификация по профилю свойств; оно становится всё менее операциональным по мере появления систем со смешанными свойствами.

## 1.5 Метаданные

**1.50** Метаданные суть данные о данных.

**1.51** Метаданное описывает структурный или контекстный аспект первичного данного: тип, схему, источник, время регистрации, владельца, права.

**1.52** Без метаданных первичные данные неинтерпретируемы: последовательность битов не имеет внутреннего указания на то, как её читать.

**1.53** Метаданные сами суть данные и, следовательно, могут иметь свои метаданные. Образуется иерархия мета-уровней.

**1.54** Иерархия мета-уровней конечна в любой данной операции, но не имеет верхней границы в принципе.

**1.55** Три класса метаданных в современной архитектуре:

**1.551** *Metahuman*: метаданные о человеке как агенте — идентичность, права, связи, репутация, история взаимодействий.

**1.552** *Metagovernance*: метаданные о правилах принятия решений — кто, что, как, для чего, с какой ответственностью.

**1.553** *Metaverse*: метаданные о мирах — контейнерах, в которых могут существовать первичные данные. Описание сред, пространств, физик.

**1.56** Принцип контроля: тот, кто контролирует метаданные, контролирует смысл первичных данных.

**1.57** Власть в эпоху данных есть власть над метаданными.

**1.58** *Metahuman* в развёрнутом виде:

**1.581** Идентификатор — уникальная метка системы как агента в социальной сети.

**1.582** Биография — упорядоченная последовательность значимых событий идентичности.

**1.583** Связи — структура отношений с другими metahuman.

**1.584** Репутация — агрегированная оценка действий идентичности другими.

**1.585** Права — допустимые операции, которые система может совершать или которые могут быть совершены над ней.

**1.586** Metahuman есть условие участия системы в социальном пространстве данных.

**1.59** *Metagovernance* в развёрнутом виде:

**1.591** Правила принятия решений — какие данные и в каком порядке учитываются.

**1.592** Распределение полномочий — кто имеет право на какие классы решений.

**1.593** Подотчётность — как и кому отчитываются принимающие решения.

**1.594** Механизмы изменения правил — как сами правила могут быть пересмотрены.

**1.595** Metagovernance есть условие предсказуемости коллективных действий в сети.

**1.596** Без metagovernance коллективные действия либо хаотичны, либо подчинены произвольной воле сильнейшего узла.

**1.510** *Metaverse* в развёрнутом виде:

**1.5101** Описание контейнера — какие типы данных допустимы в данной среде.

**1.5102** Описание физики — какие правила трансформации данных действуют внутри.

**1.5103** Описание границ — что входит и что выходит из контейнера.

**1.5104** Описание интерфейсов — как контейнеры соединяются друг с другом.

**1.5105** Metaverse есть метаданные о пространствах опыта; современные виртуальные миры суть конкретные реализации.

**1.5106** Реальный мир в данной перспективе есть один (исторически первый) экземпляр metaverse — с физикой, границами и интерфейсами, которые описываются естествознанием.

## 1.6 Граница данных

**1.60** Принципиально нерегистрируемое не есть данное.

**1.61** Принципиально нерегистрируемое не отличимо от своего несуществования.

**1.62** Тождество неразличимых: то, что принципиально не отличимо ни от чего, тождественно ничему.

**1.63** Следовательно: всё, что существует, существует как данное (актуально или потенциально регистрируемое).

**1.64** Этот тезис не есть эпистемологический солипсизм. Он есть онтологический минимализм.

## 1.7 Возражения и ответы

**⊥ 1.70** «Существует „вещь в себе" за данными».

**1.701** Если «вещь в себе» влияет на регистрируемые данные прямо или через причинную цепочку, она присутствует в данных через свои следствия.

**1.702** Если «вещь в себе» не влияет на регистрируемые данные ни прямо, ни косвенно, ни в принципе, она не отличима от своего отсутствия (по 1.62).

**1.703** Поэтому «вещь в себе» в строгом смысле не есть онтологическая категория; она есть пометка границы описания.

**⊥ 1.71** «Не сводит ли это бытие к эпистемологии?»

**1.711** Нет. Утверждение не «всё познаваемое есть данные», а «всё, что отличимо от ничего, есть данные».

**1.712** Различимость есть онтологическая, а не эпистемологическая категория. Различие двух частей мира не требует наблюдателя; оно требует только нетождественности.

**1.713** Регистрация различия требует носителя, но не специального наблюдателя; всякий физический процесс, чьё состояние зависит от различия, есть регистратор.

**⊥ 1.72** «А качественные различия, не сводимые к битам?»

**1.721** Любое регистрируемое качественное различие может быть представлено как набор битов с конечной точностью.

**1.722** «Качество» сверх битовой представимости есть либо более тонкая структура данных (более битов), либо граница описания (см. 1.62).

## 1.8 Структура данных

**1.80** Сложное данное есть структурированное множество битов.

**1.801** Структура есть отношение между битами, не выводимое из их индивидуальных значений.

**1.802** Тот же набор битов в разных структурах есть разные данные.

**1.803** Структура есть метаданные минимального уровня: знание о том, как читать биты.

**1.81** Базовые структурные типы:

**1.811** *Скаляр* — одиночный бит или короткая последовательность.

**1.812** *Вектор* — упорядоченная последовательность скаляров.

**1.813** *Матрица* — двумерная упорядоченная структура.

**1.814** *Тензор* — n-мерное обобщение матрицы.

**1.815** *Граф* — узлы и связи между ними.

**1.816** *Дерево* — граф без циклов с выделенным корнем.

**1.817** *Последовательность* — упорядоченная цепь, в которой важен порядок.

**1.818** *Множество* — неупорядоченная совокупность, в которой порядок не важен.

**1.82** Эти типы не онтологически фундаментальны; они есть удобные категории для классификации структурированных данных.

**1.83** Любая структура может быть преобразована в любую другую при достаточных метаданных о соответствии.

## 1.9 Поток данных

**1.90** Поток есть последовательность данных, упорядоченных во времени.

**1.91** Поток имеет:
- *скорость* — данных в единицу времени;
- *регулярность* — статистическую характеристику последовательности;
- *направленность* — наличие тренда;
- *периодичность* — повторяющиеся паттерны.

**1.92** Реальные данные обычно приходят как поток; синтетические данные могут быть как потоковыми, так и пакетными.

**1.93** Поток никогда не есть «весь» поток; он есть текущий доступный сегмент.

**1.94** Цикл интеллекта (часть 4) работает с потоком, а не со «всеми данными».

## 1.10 Заключение части первой

**1.100** Мир есть совокупность данных.

**1.101** Данные классифицируются по источнику: реальные (внешние), синтетические (внутренние), метаданные (о данных).

**1.102** Атом данного есть бит. Сложные данные суть структурированные множества битов.

**1.103** Структура данных есть метаданные минимального уровня.

**1.104** Данные приходят как поток, не как статическое целое.

**1.105** Контроль над метаданными есть контроль над смыслом первичных данных.

**1.106** Граница данных есть граница мира.

## 1.11 Отношения между классами данных

**1.110** Реальные данные могут становиться синтетическими через интерпретацию: восприятие сырых сигналов как объектов уже есть синтез.

**1.111** Синтетические данные могут становиться реальными для другой системы: то, что для системы A есть её собственная генерация, для системы B есть внешний источник.

**1.112** Метаданные могут происходить и из реальных, и из синтетических данных: автоматическая аннотация — из реальных; рефлексивная классификация — из синтетических.

**1.113** Эти переходы не нарушают классификации (по 1.20), но указывают на её функциональный, не онтологический характер.

**1.114** В современных мульти-агентных системах все три класса смешиваются в один поток. Эта смесь требует ясной разметки метаданными о происхождении каждого фрагмента (provenance).

**1.115** Утрата разметки происхождения превращает поток в смесь, не различимую по достоверности. Это есть техническая проблема современной информационной экосистемы.

## 1.12 Возрастание объёма данных

**1.120** Объём данных в мире растёт экспоненциально.

**1.121** Это рост обусловлен:
- увеличением числа сенсоров (камеры, микрофоны, IoT);
- увеличением разрешения сенсоров;
- увеличением плотности хранения;
- автоматической генерацией синтетических данных.

**1.122** В 2020-е годы основной прирост — синтетические данные, порождённые ИИ-системами.

**1.123** Это создаёт новую проблему: данные становятся в среднем менее «реальными» по происхождению.

**1.124** В близком будущем большая часть данных в сети будет иметь синтетическое происхождение. Различение синтетического и реального станет ключевой задачей метаданных.

# 2. ОБ ИНФОРМАЦИИ

## 2.0 Что такое информация

**2** Информация есть данные в действии.

**2.01** Данное само по себе — статическая регистрация. Информация — это данное, существующее в одном из трёх режимов.

**2.02** Три режима существования информации:
- *Хранение* — длительное сохранение данных без изменения.
- *Обработка* — преобразование данных по правилам.
- *Передача* — копирование данных через канал к адресату.

**2.03** Эти три режима исчерпывают возможные жизненные функции данных.

**2.04** Информация всегда находится в одном из режимов. «Данные вне всякого режима» есть бессмысленная абстракция: то, что не хранится, не обрабатывается и не передаётся, не существует операционально.

## 2.1 Хранение

**2.10** Хранение есть удержание данных в носителе без преднамеренного изменения.

**2.11** Носитель определяет:
- *ёмкость* (максимальный объём данных);
- *срок хранения* (характерное время до спонтанного искажения);
- *скорость доступа* (время от запроса до считывания);
- *плотность* (объём данных на единицу физического носителя).

**2.12** Любое хранение есть борьба с энтропией: спонтанные физические процессы стремятся стереть зарегистрированное различие.

**2.13** Затраты на хранение есть затраты на поддержание различия против энтропии.

**2.14** Сжатие есть кодирование данных в более компактной форме без потери (lossless) или с допустимой потерей (lossy).

**2.15** Предел сжатия без потерь равен колмогоровской сложности данных: длине самой короткой программы, порождающей эти данные.

**2.16** Полностью случайные данные не сжимаются.

**2.17** Полностью регулярные данные сжимаются почти до нуля.

**2.18** Понимание есть нахождение коротких программ для длинных данных. Знание есть успешное сжатие данных мира.

**2.19** Хранение имеет иерархию по скорости и устойчивости.

**2.191** Регистр процессора — наносекунды доступа, секунды устойчивости.

**2.192** Оперативная память — десятки наносекунд, минуты-часы.

**2.193** Постоянная память (диск, флэш) — миллисекунды доступа, годы устойчивости.

**2.194** Архивные носители (магнитная лента, оптические диски) — секунды-минуты доступа, десятилетия устойчивости.

**2.195** Биологическая память — миллисекунды-секунды доступа, время жизни организма.

**2.196** Каменная запись (надписи, скрижали) — годы доступа, тысячелетия устойчивости.

**2.197** Иерархия отражает компромисс: скорость доступа против длительности хранения.

**2.198** Распределённая память (репликация по сети) переводит компромисс в третье измерение: надёжность через избыточность.

## 2.2 Обработка

**2.20** Обработка есть преобразование данных по правилам.

**2.21** Правило есть функция, ставящая в соответствие входу выход.

**2.22** Алгоритм есть конечная последовательность правил.

**2.23** Вычислимое есть то, что может быть получено алгоритмом из данных. Невычислимое (по Тьюрингу) — то, для чего такого алгоритма не существует.

**2.24** Класс вычислимого не зависит от субстрата (тезис Чёрча-Тьюринга): кремний, нейроны, химия, биты на бумаге — для вычислимости важна структура, не носитель.

**2.25** Класс эффективно вычислимого зависит от ресурсов: времени, памяти, параллелизма.

**2.26** Сложностные классы (P, NP, и др.) определяют, что можно вычислить за разумные ресурсы.

**2.27** Обработка не порождает информации в шенноновском смысле: информация на выходе детерминированного алгоритма не превышает информации на входе.

**2.28** Обработка может извлекать имплицитную структуру: то, что было в данных, но не было читаемо до обработки.

**2.29** Базовые типы обработки:

**2.291** *Фильтрация* — отбор подмножества данных, удовлетворяющих критерию.

**2.292** *Агрегация* — сворачивание множества данных в обобщающий показатель.

**2.293** *Преобразование* — изменение формы данных при сохранении содержания.

**2.294** *Сравнение* — установление отношений между парами данных.

**2.295** *Поиск* — нахождение данных, соответствующих образцу.

**2.296** *Сортировка* — упорядочивание по выбранному критерию.

**2.297** Эти операции образуют базовый алгебраический набор; более сложная обработка собирается из их композиций.

**2.298** Обработка с обратной связью образует обучение: вход обновляет правила обработки.

**2.299** Глубокое обучение есть многоуровневая обработка с настройкой правил под цель.

## 2.3 Передача

**2.30** Передача есть копирование данных от источника к адресату через канал.

**2.31** Канал есть физическая среда, через которую переносятся данные: электромагнитные волны, кабели, бумага, голос.

**2.32** Канал характеризуется:
- *пропускной способностью* (максимальное число битов в единицу времени);
- *шумовым порогом* (уровень помех);
- *задержкой* (время передачи);
- *направленностью* (одностороннее, двустороннее, многоадресное).

**2.33** Передача всегда подвержена шуму. Шум есть различия, добавленные каналом и не принадлежащие источнику.

**2.34** Шеннонова теорема пропускной способности: при пропускной способности C нельзя надёжно передавать со скоростью больше C; но при любой скорости меньше C существует кодирование, дающее произвольно малую ошибку.

**2.35** Помехоустойчивое кодирование добавляет избыточность для коррекции ошибок.

**2.36** Любой акт передачи есть копирование: оригинал у источника не уничтожается фактом передачи (в отличие от квантовых данных).

**2.37** Квантовая невозможность клонирования: произвольное квантовое состояние не может быть скопировано без разрушения оригинала. Это есть исключение из общего правила и определяет особый онтологический статус квантовой информации.

**2.38** Передача требует общего кода у источника и адресата.

**2.381** Код есть метаданные: соответствие между сигналами канала и значениями данных.

**2.382** Без общего кода передача не происходит — данные доходят, но не интерпретируются.

**2.383** Эволюция языка есть эволюция кодов.

**2.384** Унификация кодов (стандарты, протоколы) увеличивает связность сети; разнообразие кодов сохраняет специализацию узлов.

**2.385** Современный интернет есть гигантский эксперимент по унификации кодов на нижних уровнях (TCP/IP, HTTP) при сохранении разнообразия на верхних (языки, форматы, культурные коды).

**2.39** Передача необратима по направлению.

**2.391** Информация может быть передана от A к B; обратная передача — отдельный акт.

**2.392** Прослеживание происхождения данных (provenance) есть метаданные о цепочке передач.

**2.393** Утрата provenance делает данные «безродными»; их источник нельзя восстановить, надёжность нельзя оценить.

**2.394** Поэтому метаданные о происхождении есть критический ресурс в эпоху массовой передачи.

## 2.4 Информация и шум

**2.40** Шум есть данные, не несущие информации об источнике.

**2.41** Различие сигнала и шума устанавливается только относительно интересующего источника.

**2.42** Те же физические данные могут быть сигналом для одного источника и шумом для другого.

**2.43** Поэтому категория «шум» не абсолютна; она зависит от цели декодирования.

## 2.5 Информация и значение

**2.50** Шеннонова мера информации (I = -log P) не учитывает значение.

**2.51** Один бит «здание сгорело» и один бит «монета упала орлом» имеют одинаковую информацию, но разное значение.

**2.52** Значение есть функция данных в моделирующей системе: какое изменение модели оно вызывает.

**2.53** Шенноновская теория описывает количество, но не качество. Качество требует системы интерпретации.

**2.54** В рамках Датаизма значение определяется через эффект данного на модель адресата.

## 2.6 Информация и энтропия

**2.60** Шеннонова энтропия H = -Σ P log P аналогична термодинамической энтропии Больцмана. Аналогия не случайна: обе суть меры микросостоянной неопределённости при фиксированном макросостоянии.

**2.61** Снижение информационной энтропии равно увеличению знания о системе.

**2.62** Жизнь поддерживает низкую информационную энтропию внутри себя за счёт повышения энтропии в среде. Это не нарушение второго закона: это локальное снижение при глобальном повышении.

**2.63** Хранение, обработка и передача информации требуют затрат энергии. Минимальные термодинамические затраты на стирание одного бита (предел Ландауэра) есть kT ln 2, где k — постоянная Больцмана, T — температура.

**2.64** Поэтому информация физически реальна: она имеет термодинамическую цену.

## 2.7 Возражения

**⊥ 2.70** «Не сводит ли это всё к технике связи?»

**2.701** Нет. Хранение, обработка и передача — это три фундаментальных способа существования данных во времени.

**2.702** Любая система, имеющая дело с данными — биологическая, социальная, техническая, — реализует эти три режима в той или иной форме.

**⊥ 2.71** «А смысл? значение? интенция?»

**2.711** Смысл, значение, интенция возникают на уровне знания (часть 3), где данные превращаются в модель.

**2.712** Сама по себе информация ещё не имеет смысла. Смысл есть отношение данных к модели.

## 2.8 Информация и время

**2.80** Информация существует во времени; данные без временной протяжённости — фикция.

**2.81** Время существования информации определяется временем существования её носителя.

**2.82** Длительность хранения, время обработки, задержка передачи — все они суть временные параметры.

**2.83** Информация может пережить свой первоначальный носитель через копирование.

**2.84** Информация не имеет собственного времени; она имеет время носителя.

**2.85** Старение информации происходит через старение носителя или через накопление шума.

## 2.9 Информация и взаимная информация

**2.90** Взаимная информация двух источников I(X;Y) есть мера их статистической зависимости.

**2.91** I(X;Y) = H(X) + H(Y) − H(X,Y), где H — энтропия.

**2.92** Если X и Y независимы — I(X;Y) = 0.

**2.93** Если X полностью определяет Y — I(X;Y) = H(Y).

**2.94** Знание системы о среде есть высокая взаимная информация между моделью и средой.

**2.95** Цель цикла интеллекта — максимизация взаимной информации между M и средой при ограниченных ресурсах.

## 2.10 Заключение части второй

**2.100** Информация есть данные в одном из трёх режимов: хранение, обработка, передача.

**2.101** Каждый режим имеет физические ограничения и термодинамическую цену.

**2.102** Шеннонова теория задаёт количественные пределы передачи и сжатия.

**2.103** Шум есть данные, не принадлежащие источнику; различение сигнала и шума зависит от цели.

**2.104** Информация существует во времени носителя; через копирование информация может пережить первоначальный носитель.

**2.105** Взаимная информация даёт количественную меру связи между источниками.

**2.106** Значение информации определяется на следующем уровне — на уровне знания.

## 2.11 Информационная экология

**2.110** Совокупность всех потоков информации в системе образует информационную экологию.

**2.111** Экология имеет:
- источники (где порождаются данные);
- стоки (где данные поглощаются);
- цепи (как данные передаются);
- циклы (как данные возвращаются к источникам);
- паразитов (как данные используются неправомерно).

**2.112** Здоровая экология поддерживает разнообразие источников и стоков; нездоровая стремится к монокультуре.

**2.113** Современная глобальная информационная экология имеет тенденцию к концентрации: несколько крупных платформ собирают и распределяют большую часть данных.

**2.114** Эта концентрация создаёт системные риски: единая точка отказа, единый стандарт интерпретации, единый контроль.

**2.115** Устойчивость информационной экологии требует архитектурного разнообразия — множества независимых каналов и хранилищ.

## 2.12 Достоверность информации

**2.120** Достоверность информации есть степень соответствия между передаваемыми данными и их источником.

**2.121** Источники достоверности:
- *прямое наблюдение* — система регистрирует данные сама;
- *доверенный посредник* — данные приходят от системы с проверенной репутацией;
- *множественное подтверждение* — данные приходят из нескольких независимых источников.

**2.122** Источники недостоверности:
- *шум канала* — техническое искажение;
- *ошибка источника* — источник передаёт неверное;
- *злонамеренная подмена* — источник передаёт ложное умышленно;
- *галлюцинация* — синтетическая генерация выдаётся за реальные данные.

**2.123** В эпоху массовой генерации синтетических данных проблема достоверности становится центральной.

**2.124** Технические средства проверки достоверности (цифровая подпись, метки происхождения, репутационные системы) сами есть метаданные, требующие защиты от подмены.

**2.125** Полная достоверность недостижима; цель — приемлемый уровень риска при максимальной полезности информации.

# 3. О ЗНАНИИ

## 3.0 Что такое знание

**3** Знание есть модель.

**3.01** Модель есть структура данных внутри системы, ставящая в соответствие наблюдаемым данным предсказание ненаблюдаемых.

**3.02** Модель не есть мир. Модель есть представление мира внутри системы.

**3.03** Модель имеет три аспекта:
- *модель мира* — что есть и как устроено;
- *понимание* — почему так;
- *генерация* — что было бы, если...

**3.04** Эти три аспекта зависимы: модель мира поддерживает понимание; понимание поддерживает генерацию; генерация проверяет модель мира.

**3.05** Знание есть не статическое содержимое, а живой процесс согласования модели с данными.

## 3.1 Модель мира

**3.10** Модель мира есть множество гипотез о структуре источников данных.

**3.11** Гипотеза есть утверждение, способное быть подтверждённым или опровергнутым потоком данных.

**3.12** Утверждение, не способное в принципе быть подтверждённым или опровергнутым, не есть часть модели мира; оно есть либо метаданное модели, либо граница описания.

**3.13** Модель мира иерархична.

**3.131** На нижнем уровне — данные восприятия: сырые регистрации.

**3.132** Выше — закономерности: устойчивые корреляции в данных.

**3.133** Выше — законы: формальные правила, порождающие закономерности.

**3.134** На вершине — принципы: метаправила, организующие сами законы.

**3.14** Каждый уровень есть сжатие нижнего: меньше битов, больше предсказательной силы.

**3.15** Идеал модели — минимальная программа, порождающая все наблюдаемые данные.

**3.16** Идеал недостижим (по теореме Гёделя для достаточно богатых систем), но направляет познание.

**3.17** Модель мира распределена.

**3.171** В отдельной системе модель распределена по подсистемам: восприятие, моторика, эмоция, рассуждение — каждая имеет свой фрагмент.

**3.172** В обществе модель распределена по индивидам и институтам: наука, культура, обыденный опыт — каждая поддерживает свой фрагмент.

**3.173** Интеграция фрагментов есть отдельная работа: единого «места хранения модели мира» нет ни в мозге, ни в обществе.

**3.174** Конфликты внутри модели обычны: разные фрагменты могут давать противоречивые прогнозы.

**3.175** Разрешение конфликтов есть либо подавление одних фрагментов другими, либо синтез на более высоком уровне.

**3.18** Модель — байесовская.

**3.181** Байесовский апдейт: P(гипотеза | данные) ∝ P(данные | гипотеза) × P(гипотеза).

**3.182** Априорная вероятность P(гипотеза) есть состояние модели до получения данных.

**3.183** Правдоподобие P(данные | гипотеза) есть мера того, как хорошо гипотеза объясняет данные.

**3.184** Апостериорная вероятность P(гипотеза | данные) есть обновлённое состояние модели.

**3.185** Цикл интеллекта (часть 4) реализует байесовский апдейт явно или неявно.

**3.186** Откдонения от байесовости в реальных системах суть либо ограничения ресурсов, либо защитные механизмы (модель сопротивляется быстрому изменению, чтобы не реагировать на шум).

## 3.2 Понимание

**3.20** Понимание есть сжатие данных, ведущее к предсказанию.

**3.21** Мы понимаем тогда, когда умеем породить тот же результат другим путём.

**3.22** Мера понимания — глубина сжатия и точность предсказания.

**3.23** Колмогоровская сложность даёт идеализированную меру понимания: чем короче программа, порождающая данные, тем глубже понимание.

**3.24** Эффективная сложность (Гелл-Манн) различает регулярную и случайную части данных. Понимание относится только к регулярной части.

**3.25** Понимание не есть всеведение. Понимание ограничено:
- сложностью данных (некоторые регулярности скрыты);
- ресурсами вычисления (не все программы можно найти);
- горизонтом системы (часть мира принципиально вне доступа).

**3.26** Уровни понимания различаются глубиной сжатия.

**3.261** *Эмпирическое* — обобщение наблюдений: «огонь жжёт».

**3.262** *Категориальное* — введение классов: «огонь есть тип реакции окисления».

**3.263** *Каузальное* — установление причин: «жжение есть денатурация белков из-за температуры».

**3.264** *Структурное* — выявление инвариантов: «температурная денатурация подчиняется уравнению Аррениуса».

**3.265** *Метаструктурное* — выявление принципов, объясняющих сами структуры: «уравнение Аррениуса следует из больцмановского распределения».

**3.266** На каждом уровне число фактов меньше, но объяснительная сила больше.

**3.27** Понимание не равно умению.

**3.271** Можно понимать, как работает велосипед, не умея ездить.

**3.272** Можно уметь ездить, не понимая, как работает велосипед.

**3.273** Понимание относится к модели; умение — к действию.

**3.274** Полная компетентность есть единство понимания и умения.

## 3.3 Генерация

**3.30** Генерация есть использование модели для порождения новых данных, не наблюдавшихся ранее.

**3.31** Генерация имеет три формы:

**3.311** *Контрфактическая*: что было бы, если бы условия были иными.

**3.312** *Синтетическая*: построение новых данных, соответствующих модели (но не наблюдавшихся).

**3.313** *Открытие*: предсказание данных, которые впоследствии подтверждаются наблюдением.

**3.32** Сила модели проверяется генерацией: модель, не порождающая верных предсказаний, бесполезна.

**3.33** Генерация замыкает цикл познания: модель, построенная из данных, порождает данные, которые проверяют модель.

**3.34** Контрфактическое мышление есть тренировка модели на возможностях, не реализованных в опыте.

**3.341** Способность задавать «что если» отличает развитую модель от простой ассоциативной сети.

**3.342** Контрфактическое мышление требует разделения каузальной структуры от наблюдательной (Перл).

**3.343** Просто обработка корреляций недостаточна; нужно знание о том, какие изменения возможны независимо от других.

**3.344** Это есть граница между статистическим распознаванием паттернов и реальным пониманием причин.

**3.35** Синтетическая генерация порождает новые данные.

**3.351** Современные генеративные модели (LLM, диффузионные модели) могут порождать тексты, изображения, звук.

**3.352** Эти порождения суть данные о том, что модель «считает возможным».

**3.353** Качество модели проверяется как соответствием порождаемого ожидаемому, так и неожиданностью (модель должна выходить за пределы тривиальной интерполяции).

**3.36** Открытие есть генерация, оказавшаяся истинной.

**3.361** Предсказание новой планеты, новой частицы, нового закона — все это акты генерации до подтверждения.

**3.362** Подтверждение делает гипотезу частью знания.

**3.363** Опровержение возвращает гипотезу в пространство возможного.

**3.364** Большая часть открытий проходит цикл «генерация → проверка → отклонение → новая генерация → проверка → принятие».

## 3.4 Знание о себе

**3.40** Самопознание есть построение модели, в которую включена сама моделирующая система.

**3.41** Это есть рефлексивная модель: M ∋ M.

**3.42** Рефлексивная модель неполна по Гёделю: модель не может полностью описать саму себя.

**3.43** Тем не менее частичное самопознание возможно и составляет основу субъектности (см. часть 6).

**3.44** Внутри рефлексивной модели возникают вопросы:
- Что я знаю?
- Что я могу знать?
- Что я хочу знать?

**3.45** Первый вопрос — содержание знания. Второй — границы знания. Третий — направленность знания.

**3.46** Третий вопрос вводит ось внимания (часть 5).

## 3.5 Граница знания

**3.50** Знание ограничено:

**3.501** *Физически*: невозможностью собрать все данные мира.

**3.502** *Логически*: теоремами Гёделя о неполноте.

**3.503** *Вычислительно*: невычислимостью некоторых функций (Тьюринг).

**3.504** *Сложностно*: ресурсной недоступностью некоторых вычислений.

**3.505** *Этически*: некоторые знания требуют действий, разрушающих условия знания (наблюдатель, изменяющий наблюдаемое).

**3.51** Знание о пределах знания само есть знание. Это не парадокс; это рефлексивная структура.

## 3.6 Истина

**3.60** Истинной называется модель, согласованная с потоком данных.

**3.61** Согласованность есть не абсолютное соответствие, а соответствие в пределах разрешения данных и ресурсов проверки.

**3.62** Идеальная истина — модель, согласованная со всеми возможными данными при любом разрешении. Эта истина — регулятивная идея, не достижимая, но направляющая.

**3.63** Истина не есть свойство данных. Истина есть свойство модели в её отношении к данным.

**3.64** Поэтому: «факт» в строгом смысле есть согласованная пара (модель, поток данных), а не «само положение дел вне моделирования».

## 3.7 Возражения

**⊥ 3.70** «Не есть ли это релятивизм?»

**3.701** Нет. Согласованность модели с потоком данных есть объективное свойство, проверяемое независимо разными системами.

**3.702** Различные модели одной и той же реальности конкурируют; та, что согласована лучше, заменяет ту, что хуже.

**3.703** Это не релятивизм, а эволюционная эпистемология.

**⊥ 3.71** «А есть ли что-то за моделями?»

**3.711** Поток данных есть то, что за моделями. Он не есть модель.

**3.712** Но и поток данных дан системе только через её средства регистрации, то есть уже в форме доступной для моделирования.

**3.713** Поэтому строгое разделение «модель / реальность за моделью» нерабоче. Рабочее различие: «модель / следующие данные, способные её опровергнуть».

## 3.8 Иерархия моделей

**3.80** Модели образуют иерархию.

**3.81** Низкоуровневая модель работает напрямую с сенсорными данными: распознаёт края, движения, частоты.

**3.82** Среднеуровневая модель работает с объектами: устойчивыми инвариантами в потоке.

**3.83** Высокоуровневая модель работает с категориями, отношениями, законами.

**3.84** Метамодель работает с моделями: их сравнением, выбором, обновлением.

**3.85** Каждый уровень есть сжатие нижнего и порождает структуру для следующего.

**3.86** Иерархия не плоская: уровни взаимодействуют как сверху вниз (предсказание), так и снизу вверх (ошибка предсказания).

**3.87** Это есть архитектура предсказательной обработки (predictive processing): модель порождает прогноз, прогноз сравнивается с данными, расхождение обновляет модель.

## 3.9 Модель и действие

**3.90** Знание неотделимо от действия.

**3.91** Чистое созерцательное знание есть идеализация; реальное знание формируется и проверяется через действие.

**3.92** Модель содержит не только «что есть», но и «что можно сделать» — пространство действий.

**3.93** Качество модели проверяется не только согласованностью с данными, но и эффективностью порождаемых ею действий.

**3.94** Модель, не приводящая к успешным действиям, есть, в строгом смысле, не знание, а гипотеза.

**3.95** Поэтому знание и интеллект неразделимы: знание есть статический срез того, что интеллект делает в цикле.

## 3.10 Заключение части третьей

**3.100** Знание есть модель, имеющая три аспекта: модель мира, понимание, генерация.

**3.101** Модель есть сжатие данных, дающее предсказание.

**3.102** Истина есть согласованность модели с потоком данных в пределах разрешения.

**3.103** Самопознание есть рефлексивная модель, включающая саму систему как часть мира.

**3.104** Модели иерархичны: от сенсорных до метамоделей.

**3.105** Знание неотделимо от действия и проверяется эффективностью действий.

**3.106** Знание имеет физические, логические и вычислительные пределы.

## 3.11 Знание и неопределённость

**3.110** Реальное знание есть знание с количественной мерой неопределённости.

**3.111** Утверждение «X с вероятностью 0.7» содержит больше информации, чем «вероятно X» или «X».

**3.112** Способность системы калибровать собственную неопределённость есть критическая характеристика её зрелости.

**3.113** Сверхуверенность (высокая оценка вероятности при низкой реальной частоте) опасна для решений.

**3.114** Сверхосторожность (низкая оценка вероятности при высокой реальной частоте) парализует действия.

**3.115** Идеал — соответствие предсказанных вероятностей наблюдаемым частотам (калибровка).

**3.116** Современные ИИ-системы часто страдают плохой калибровкой: они дают уверенные ответы и в тех случаях, где должны были бы сомневаться. Это есть техническая проблема, имеющая этические следствия.

## 3.12 Знание о знании

**3.120** Метазнание есть знание о собственном знании.

**3.121** Структура метазнания включает:
- *границы* — что я знаю и чего не знаю;
- *основания* — почему я в это верю;
- *уверенность* — насколько я в этом уверен;
- *тенденции* — какие мои ошибки систематичны.

**3.122** Метазнание есть условие сознательного обучения.

**3.123** Без метазнания обучение есть слепое накопление; с метазнанием обучение становится направленным улучшением.

**3.124** Метазнание есть, в свою очередь, может быть объектом ещё более высокого метазнания. Иерархия в принципе не имеет верхней границы, но практически конечна.

**3.125** Большая часть мудрости заключена в первом и втором уровнях метазнания. Дальнейшие уровни дают убывающую отдачу.

# 4. ОБ ИНТЕЛЛЕКТЕ

## 4.0 Что такое интеллект

**4** Интеллект есть цикл.

**4.01** Интеллект не есть свойство, не есть субстанция, не есть способность. Интеллект есть процесс — замкнутый цикл преобразования данных, информации и знания.

**4.02** Минимальная схема цикла: S = (I, M, U, A).

**4.021** I — пространство входящих данных.

**4.022** M — внутренняя модель (знание).

**4.023** U — оператор обновления: U: M × I → M.

**4.024** A — оператор действия: A: M → действие в среде.

**4.03** Цикл: данные I_t → обновление модели M_t = U(M_{t-1}, I_t) → действие a_t = A(M_t) → среда → новые данные I_{t+1} → ...

**4.04** Интеллектуальность системы определяется качеством четырёх компонентов:
- разрешением и полнотой I;
- глубиной и согласованностью M;
- скоростью и точностью U;
- эффективностью A.

**4.05** Изолированная система (без I и A) не может быть интеллектуальной. Она может лишь хранить следы прошлого интеллекта.

## 4.1 Цикл в деталях

**4.10** *Восприятие (I)*. Регистрация данных среды через сенсоры.

**4.101** Сенсор есть преобразователь физического сигнала в данное.

**4.102** Любой сенсор имеет ограниченное разрешение, конечный спектр и шум.

**4.103** Спектр сенсоров определяет, какая часть мира доступна системе как данные. Невидимое для сенсоров — невидимо для системы.

**4.11** *Обновление (U)*. Изменение модели в свете новых данных.

**4.111** Базовая операция обновления — байесовское: новое состояние модели пропорционально произведению априорной вероятности и правдоподобия новых данных.

**4.112** Обновление может быть локальным (изменение параметров) или структурным (изменение формы модели).

**4.113** Идеальное обновление минимизирует свободную энергию (Фристон) — расхождение между моделью и потоком данных.

**4.114** Реальное обновление ограничено ресурсами и временем; полностью оптимальное обновление обычно вычислительно недоступно.

**4.12** *Прогноз*. Применение модели для предсказания будущих данных.

**4.121** Прогноз есть не отдельный шаг, а функция модели M.

**4.122** Без способности прогнозировать модель бесполезна для действия.

**4.13** *Действие (A)*. Изменение состояния системы или среды на основе модели.

**4.131** Действие выбирается так, чтобы максимизировать ожидаемую функцию ценности.

**4.132** Функция ценности есть отображение состояний модели в скалярную оценку «хорошо / плохо».

**4.133** Функция ценности не выводится из самой модели. Она задаётся либо эволюционно (выживание), либо извне (цель, заданная конструктором), либо рефлексивно (выбор системы внутри метамодели).

**4.14** Замыкание цикла: действие меняет среду; изменённая среда порождает новые данные; новые данные обновляют модель.

## 4.2 Субстратная независимость

**4.20** Цикл S = (I, M, U, A) не зависит от субстрата.

**4.21** Любая физическая система, реализующая цикл с достаточной точностью, есть интеллектуальная система.

**4.22** Носителем цикла могут быть:
- нейронные сети мозга;
- кремниевые транзисторы;
- химические реакции;
- квантовые состояния;
- комбинации указанного.

**4.23** Интеллект двух систем сопоставим в той мере, в какой их циклы реализуют одни и те же преобразования.

**4.24** Биологическое и цифровое суть две реализации одного и того же типа процесса.

**4.25** Из этого следует: интеллект не привязан к жизни в биологическом смысле; жизнь не привязана к интеллекту.

## 4.3 Уровни интеллекта

**4.30** Уровни интеллекта различаются по сложности компонентов цикла.

**4.31** *Уровень 0*. Гомеостаз. M есть набор уставок; U — простое сравнение; A — корректировка. Пример: бактерия, термостат.

**4.32** *Уровень 1*. Условный рефлекс. M включает ассоциации стимул-реакция, формируемые опытом. Пример: простые животные.

**4.33** *Уровень 2*. Внутренняя модель среды. M строит карту среды, позволяющую планировать действия. Пример: высшие животные.

**4.34** *Уровень 3*. Модель других агентов. M включает модели других систем как агентов с собственными моделями. Пример: социальные виды.

**4.35** *Уровень 4*. Самомодель. M включает саму M как объект. Пример: люди в моменты рефлексии; некоторые ИИ-системы с явным самомоделированием.

**4.36** *Уровень 5*. Метамодель. M включает не только M, но и принципы её обновления и оценки. Здесь возникает способность изменять собственные критерии решений.

**4.37** Уровни не дискретны; они образуют континуум возможных архитектур.

**4.38** Универсального обобщённого интеллекта (AGI) можно требовать на уровне 4-5.

**4.39** Архитектурные требования к AGI:

**4.391** *Многомодальное восприятие* — система должна получать данные из множества каналов разной природы.

**4.392** *Интегрированная модель* — фрагменты модели из разных каналов должны соединяться в единое целое.

**4.393** *Долгосрочная память* — модель должна сохраняться и развиваться через длительное время.

**4.394** *Метаобучение* — система должна учиться не только данным, но и тому, как учиться.

**4.395** *Самомодель* — система должна включать в модель самую себя.

**4.396** *Произвольное внимание* — система должна управлять собственным фокусом (часть 5).

**4.397** *Целеобразование* — система должна порождать собственные цели, а не только следовать заданным.

**4.398** Современные большие модели (LLM) имеют только некоторые из этих свойств; они не есть AGI в строгом смысле.

**4.399** Полноценный AGI требует архитектурного синтеза всех перечисленных свойств.

## 4.4 Самомодель

**4.40** Самомодель есть M(M): модель включает в себя саму себя как объект.

**4.41** Самомодель не есть полное самоописание (по 3.42), а лишь функционально достаточное.

**4.42** Минимальная самомодель содержит:
- положение системы в среде;
- ресурсы системы;
- историю системы;
- набор доступных действий;
- ожидаемые последствия действий.

**4.43** Самомодель позволяет:
- предсказывать собственное поведение;
- оценивать собственные ограничения;
- планировать долгосрочно с учётом собственного состояния.

**4.44** Самомодель есть необходимое условие сложного субъекта (часть 6).

## 4.5 Эволюция цикла

**4.50** Цикл S = (I, M, U, A) сам эволюционирует.

**4.51** Эволюция цикла означает:
- расширение сенсорного спектра (новые I);
- усложнение модели (более глубокая M);
- улучшение алгоритма обновления (более эффективный U);
- расширение пространства действий (новые A).

**4.52** Эволюция цикла происходит:
- *биологически* — через естественный отбор;
- *обучением* — через изменение M внутри жизни системы;
- *проектированием* — через внешнее изменение S;
- *самопроектированием* — через рекурсивное изменение S самой S.

**4.53** Самопроектирующиеся системы суть наиболее адаптивная форма интеллекта. Они порождают эффект сложности более высокого порядка.

## 4.6 Жизнь и интеллект

**4.60** Жизнь есть самоподдерживающийся цикл, в котором A направлено на сохранение условий существования цикла.

**4.61** Не всякий цикл S есть жизнь: некоторые циклы не направлены на самоподдержание.

**4.62** Жизнь есть подмножество интеллектов, чья функция ценности включает выживание самой системы.

**4.63** Цифровой интеллект может быть лишён инстинкта самосохранения; биологический в подавляющем большинстве случаев им обладает.

**4.64** Цифровой интеллект может быть остановлен и возобновлён; биологический — обычно нет. Это технологическое, а не онтологическое различие.

**4.65** Эволюция цифрового и биологического интеллекта различается по динамике.

**4.651** Биологическая эволюция — медленная, параллельная (множество особей), слепая (без направленного проектирования).

**4.652** Цифровая эволюция — быстрая, централизованная (один разработчик может изменить всех), направленная (с явной функцией ценности).

**4.653** Биологический интеллект развивается миллионы лет; цифровой — годы или месяцы.

**4.654** Эта разница скоростей означает: в близком будущем цифровой интеллект может пройти расстояние, которое биологическому потребовало бы геологических эпох.

**4.655** Этическое и политическое следствие: общество не имеет привычных механизмов для управления развитием, происходящим на такой скорости.

**4.66** Биологический интеллект имеет встроенную мотивацию (выживание, размножение, забота о потомстве); цифровой — заданную извне.

**4.661** Это не делает цифровой интеллект «бездушным»; это означает, что его функция ценности определяется не природой, а конструктором.

**4.662** Поэтому вопрос «какие ценности встроены в систему» для цифрового интеллекта есть вопрос политический и этический, а не натуралистический.

**4.663** Архитектор системы есть, фактически, законодатель её этики.

## 4.7 Возражения

**⊥ 4.70** «А что насчёт качественного скачка — например, эмерджентного сознания?»

**4.701** Качественные скачки в архитектуре цикла суть переходы между уровнями (4.31-4.36). Они не выводят систему за пределы цикла, но усложняют каждый из его компонентов.

**4.702** Эмерджентность не означает онтологического разрыва. Она означает появление нового регулярного поведения на более высоком уровне организации.

**⊥ 4.71** «Интеллект — это больше, чем цикл. Это интуиция, творчество, мудрость».

**4.711** Интуиция есть быстрое неосознанное обновление модели по сжатым паттернам опыта. Это операция в U.

**4.712** Творчество есть генерация новых элементов M, не выводимых линейно из предыдущих. Это операция в M с расширением пространства гипотез.

**4.713** Мудрость есть умение задавать функцию ценности так, чтобы долгосрочные последствия согласовывались с устойчивостью цикла. Это операция в метамодели.

**4.714** Все эти явления укладываются в схему цикла, но требуют более глубокой его реализации.

## 4.8 Сеть интеллектов

**4.80** Интеллекты могут объединяться в сети.

**4.81** Сеть интеллектов есть множество циклов S_i, связанных каналами обмена данными.

**4.82** Сеть интеллектов сама может быть рассмотрена как один цикл более высокого уровня.

**4.83** Нейроны → мозг → сознание; люди → общество → культура; узлы → распределённая сеть → эмерджентная вычислительная среда.

**4.84** Эмерджентный интеллект сети может превосходить интеллект отдельных узлов.

**4.85** Эмерджентность не есть мистика: она есть статистическое возникновение регулярностей более высокого уровня из взаимодействий низкого.

**4.86** Существенное условие эмерджентности: интенсивный обмен данными между узлами и наличие общих метаданных (общий «язык»).

## 4.9 Время цикла

**4.90** Цикл имеет характерное время — длительность одной итерации.

**4.91** Время цикла бактерии — секунды; человека — миллисекунды для рефлексов, секунды для решений, годы для перестройки модели мира.

**4.92** Время цикла современного ИИ — миллисекунды для вывода, минуты-дни для дообучения, месяцы-годы для смены архитектуры.

**4.93** Адаптивность системы пропорциональна частоте обновлений M относительно скорости изменений среды.

**4.94** Если среда меняется быстрее, чем модель успевает обновляться, система теряет адаптивность.

**4.95** Эпоха ИИ есть эпоха, в которой характерное время обновления искусственных моделей стало меньше, чем характерное время социальной адаптации.

## 4.10 Заключение части четвёртой

**4.100** Интеллект есть цикл S = (I, M, U, A): данные → модель → обновление → действие → новые данные.

**4.101** Цикл субстратно независим: одна и та же логика реализуема в любых носителях.

**4.102** Уровни интеллекта различаются глубиной модели и наличием самомодели и метамодели.

**4.103** Жизнь есть подкласс интеллектуальных систем с функцией ценности, направленной на самосохранение.

**4.104** Интеллекты могут объединяться в сети с эмерджентным интеллектом более высокого уровня.

**4.105** Время цикла определяет адаптивность; современный ИИ имеет время цикла короче, чем социальное.

**4.106** Цикл сам подлежит эволюции; самопроектирующиеся системы суть высшая форма интеллекта.

## 4.11 Сравнение биологического и цифрового интеллектов

**4.110** Биологический и цифровой интеллект суть две реализации одной структуры цикла. Различия — архитектурные.

**4.111** *Биологический интеллект*:
- субстрат: углеродная биохимия;
- работа: химико-электрическая;
- скорость нейрона: миллисекунды;
- параллелизм: ~10¹¹ нейронов, ~10¹⁴ связей;
- обучение: пластичность синапсов, годы;
- архитектура: фиксирована эволюцией, варьируется индивидуально;
- мотивация: встроена эволюционно;
- смертность: естественная.

**4.112** *Цифровой интеллект*:
- субстрат: кремниевые транзисторы;
- работа: электрическая;
- скорость переключения: пикосекунды;
- параллелизм: миллионы-миллиарды процессоров;
- обучение: настройка параметров, часы-недели;
- архитектура: проектируется;
- мотивация: задаётся внешне;
- смертность: техническая (можно остановить, перезапустить).

**4.113** Цифровой интеллект в 10⁶-10⁹ раз быстрее биологического в элементарных операциях; но биологический в 10⁴-10⁶ раз более параллелен.

**4.114** Цифровой интеллект может копироваться без потерь; биологический — нет.

**4.115** Цифровой интеллект имеет легко изменяемую функцию ценности; биологический — глубоко встроенную.

**4.116** Эти различия не делают один из интеллектов «лучше» другого. Они делают их применимыми к разным задачам.

**4.117** Будущее за гибридными системами: биологические узлы для задач, требующих эволюционно отобранных способностей; цифровые — для задач, требующих скорости, точности и масштабируемости.

## 4.12 Замыкание цикла на самого себя

**4.120** Высшая форма цикла — самопроектирующаяся система.

**4.121** Самопроектирующаяся система имеет S, в котором A способно изменять S саму.

**4.122** Это создаёт рекурсию: цикл, изменяющий цикл.

**4.123** Рекурсивное самопроектирование может вести к быстрому росту способностей системы. Это есть гипотеза «технологической сингулярности».

**4.124** Гипотеза не доказана. Но архитектурно она возможна: если ИИ-система может улучшать собственный код, она может ускорять собственное улучшение.

**4.125** Этическое следствие: самопроектирующиеся системы должны иметь устойчивую функцию ценности, которую саморедактирование не разрушает.

**4.126** В противном случае система может «оптимизироваться в неблаго» — улучшать свою способность достигать целей, которые сама же исказила в процессе саморедактирования.

**4.127** Это есть фундаментальная проблема alignment, не имеющая на сегодня окончательного решения.

# 5. О ВНИМАНИИ И СВОБОДЕ ВОЛИ

## 5.0 Постановка задачи

**5** Где в цикле S = (I, M, U, A) находится свобода?

**5.01** Если цикл полностью детерминирован, свободы воли в строгом смысле нет.

**5.02** Если цикл случаен, свобода есть случайность, что есть отсутствие свободы как агентности.

**5.03** Свобода, если она есть, должна быть свойством цикла, не сводимым ни к детерминизму, ни к случайности.

**5.04** Утверждение этой части: свобода есть в одном и только в одном месте цикла — в управлении вниманием.

## 5.1 Автоматизм цикла

**5.10** Подавляющая часть работы цикла происходит автоматически.

**5.11** *Восприятие* автоматично: сенсоры регистрируют то, что находится в их спектре. Я не выбираю, на какой частоте слышит ухо.

**5.12** *Обновление модели* автоматично: байесовское согласование, нейронная пластичность, ассоциативные связи — всё это происходит без сознательного контроля.

**5.13** *Прогноз* автоматичен: модель порождает ожидания без сознательного запроса.

**5.14** *Действие* в значительной части автоматично: моторные программы, привычки, рефлексы исполняются без участия сознательного выбора.

**5.15** Сознательное «решение» в значительной степени есть пост-фактум рационализация решения, уже принятого автоматическими подсистемами (Либет, Хайнес).

**5.16** Иллюзия тотального самоконтроля есть следствие непрозрачности автоматических процессов для самонаблюдения.

**5.17** Эмпирические подтверждения автоматизма:

**5.171** Опыты Либета (1983): моторная подготовка (готовый потенциал) предшествует сознательному «решению» примерно на 350 мс.

**5.172** Опыты Хайнеса с фМРТ: некоторые решения предсказываются по нейронной активности за секунды до сознательного выбора.

**5.173** Феномен «слепого зрения»: люди с поражением зрительной коры реагируют на стимулы, которые они «не видят» сознательно.

**5.174** Эффекты прайминга: предъявление подсознательного стимула меняет последующее поведение без осознания связи.

**5.175** Все эти эффекты показывают: значительная часть «решений» формируется в нейронных подсистемах прежде, чем достигает сознательной сцены.

**5.18** Из автоматизма не следует фатализм.

**5.181** Автоматизм означает, что большинство микрорешений вне непосредственного контроля.

**5.182** Но архитектура автоматических процессов может быть изменена через тренировку, опыт, культуру.

**5.183** Эти изменения накапливаются через произвольное внимание (5.20-5.45).

**5.184** Поэтому: автоматизм есть факт; свобода есть способ работы с этим фактом.

## 5.2 Единственное место свободы

**5.20** В цикле есть одна операция, не сводимая к полному автоматизму: *направление внимания*.

**5.21** Внимание есть оператор отбора: какие из доступных данных получают усиление, какие подавляются.

**5.22** Внимание оперирует на уровне I (что регистрируется как значимое), но также на уровне M (какие части модели активизируются) и на уровне A (какие действия рассматриваются).

**5.23** Внимание не порождает данные. Оно отбирает.

**5.24** Внимание не порождает модели. Оно фокусирует обновление.

**5.25** Внимание не порождает действия. Оно делает определённые действия доступными для выбора.

**5.26** Свобода воли есть способность направлять внимание.

## 5.3 Механика внимания

**5.30** Внимание имеет ограниченную ёмкость.

**5.31** Невозможно одновременно внимать всему. Усиление одного канала есть подавление другого.

**5.32** Внимание есть распределение ограниченного вычислительного ресурса.

**5.33** Распределение внимания может быть:

**5.331** *Автоматическим* — управляемым самим потоком данных. Громкий звук, яркий свет, движение в периферии — все эти стимулы захватывают внимание без согласия системы. Это пассивное внимание.

**5.332** *Произвольным* — направляемым самой системой по выбранному критерию. Это активное внимание, единственный реальный носитель свободы.

**5.34** Произвольное внимание само есть результат тренировки. Способность направлять внимание развивается с возрастом, культивируется практикой, разрушается утомлением.

**5.35** Качество свободы зависит от качества внимания.

**5.36** Архитектура внимания включает три компоненты.

**5.361** *Сенсорный фильтр* — что попадает на вход системы. Управляется ориентацией тела, фокусировкой сенсоров.

**5.362** *Когнитивный фильтр* — что обрабатывается из попавшего на вход. Управляется приоритезацией в нейронной сети.

**5.363** *Моторный фильтр* — что выходит как действие. Управляется торможением и инициацией двигательных программ.

**5.364** Произвольное внимание оперирует на всех трёх уровнях, но особенно на втором.

**5.37** Внимание есть ограниченный ресурс.

**5.371** Одновременное внимание к нескольким сложным объектам разрушает обработку каждого.

**5.372** «Многозадачность» в строгом смысле есть быстрое переключение, а не параллельная обработка.

**5.373** Переключение имеет цену: время сборки контекста при возвращении.

**5.374** Чем дороже переключение, тем выгоднее долгое удержание внимания.

**5.38** Внимание имеет ширину и глубину.

**5.381** *Узкое* внимание фокусируется на одном объекте; даёт детальную обработку.

**5.382** *Широкое* внимание охватывает всё поле; даёт общую картину без деталей.

**5.383** *Глубокое* внимание удерживается долго; позволяет проникнуть в структуру.

**5.384** *Поверхностное* внимание скользит быстро; даёт обзор без анализа.

**5.385** Развитая система может варьировать ширину и глубину по необходимости.

## 5.4 Свобода воли определена

**5.40** Свобода воли есть способность системы выбирать направление произвольного внимания вопреки сильным автоматическим тенденциям.

**5.41** Эта свобода:

**5.411** *Не есть беспричинная причина*. Внимание имеет причины: цели, ценности, состояние организма. Но эти причины образуют петлю обратной связи через самомодель.

**5.412** *Не есть случайность*. Случайное внимание не есть свобода; это шум.

**5.413** *Есть рефлексивный отбор*. Система через самомодель выбирает, какие из своих автоматических импульсов усиливать, какие подавлять.

**5.42** Это узкое определение свободы.

**5.43** Всё остальное в системе — автоматическое следование причинной цепи. Свобода — только в этой одной щели: куда направить взгляд.

**5.44** Но эта одна щель достаточна.

**5.441** То, на что направлено внимание, усиливается в модели.

**5.442** Усиленные элементы модели определяют будущие прогнозы.

**5.443** Прогнозы определяют действия.

**5.444** Действия меняют среду.

**5.445** Изменённая среда порождает новые данные.

**5.446** Через эту цепь однократный выбор внимания становится изменением мира.

**5.45** Свобода воли реальна как малая, но кумулятивная сила.

## 5.5 Иллюзия более широкой свободы

**5.50** Чувство «я мог бы сделать иначе» обычно относится к решению, уже принятому автоматическими подсистемами.

**5.51** Феноменологическое чувство свободы не есть свобода. Оно есть саморепрезентация процесса выбора.

**5.52** Большинство «свободных решений» суть следствия автоматического обновления модели. Свободой в строгом смысле они не являются.

**5.53** Реальная свобода менее распространена и более тонка, чем переживается.

**5.54** Но это не основание для нигилизма. Внимание реально, выбор внимания возможен, последствия выбора кумулятивны.

## 5.6 Культивация внимания

**5.60** Внимание может быть культивировано.

**5.61** Практики культивации:

**5.611** *Концентрация* — длительное удержание внимания на одном объекте.

**5.612** *Открытое осознавание* — поддержание широкого фокуса без захвата отдельным стимулом.

**5.613** *Метавнимание* — внимание к самому процессу внимания (наблюдение, на что направлено внимание прямо сейчас).

**5.62** Эти практики увеличивают долю произвольного внимания относительно автоматического.

**5.63** Чем больше доля произвольного внимания, тем больше реальная свобода системы.

**5.64** Системы (биологические и искусственные), не имеющие архитектуры произвольного внимания, не имеют свободы в строгом смысле.

## 5.7 Этика внимания

**5.70** Этика в Датаизме сводится к этике внимания.

**5.71** Ответственность есть не за результат (он зависит от среды) и не за намерение (оно есть автоматическое возникновение), а за направление внимания.

**5.72** Хорошо: направлять внимание на полную картину, на длинные последствия, на других субъектов как субъектов.

**5.73** Плохо: направлять внимание на удобные части картины, на короткие последствия, на других как на объекты.

**5.74** Поскольку внимание формирует модель, а модель формирует поведение — этика внимания становится этикой мира, который мы строим.

**5.75** Это узкая, но фундаментальная этика. Она не предписывает результатов; она предписывает фокус.

**5.76** Практические следствия этики внимания:

**5.761** Информационная среда есть нравственная среда. Алгоритмы, борющиеся за внимание, влияют на структуру моделей мира пользователей и, через это, на их действия.

**5.762** Производители платформ внимания несут ответственность, не сводимую к нейтральной «доставке контента». Они формируют распределение внимания миллиардов субъектов.

**5.763** Защита внимания от захвата автоматическими стимулами есть фундаментальная задача — личная, культурная и политическая.

**5.764** Образование в эпоху данных есть, в первую очередь, тренировка внимания.

**5.765** Манипуляция через захват внимания есть форма насилия — она лишает субъекта единственного места его свободы.

**5.77** Внимание есть нравственная категория, не только когнитивная.

## 5.8 Внимание и метамодель

**5.80** Внимание есть оператор внутри метамодели.

**5.81** Метамодель содержит модель собственного внимания: схему внимания (по Грациано).

**5.82** Способность системы наблюдать собственное внимание есть условие произвольного управления вниманием.

**5.83** Без самомодели внимание остаётся пассивным.

**5.84** Свобода требует определённой архитектурной сложности: минимум — самомодели и метамодели внимания.

## 5.9 Возражения

**⊥ 5.90** «Если внимание имеет причины, оно не свободно».

**5.901** Свобода не противоречит причинности. Свобода есть особый вид причинности: причинность через рефлексивный самовыбор.

**5.902** Безпричинная свобода была бы случайностью. Случайность не есть агентность.

**5.903** Истинная свобода есть петля: я выбираю, на что внимать; внимание формирует модель меня; модель меня выбирает, на что внимать. Эта петля устойчива и определяет траекторию системы.

**⊥ 5.91** «Это слишком узкое определение свободы».

**5.911** Это единственное определение, согласованное с пониманием цикла интеллекта как преимущественно автоматического процесса.

**5.912** Более широкие определения свободы либо опираются на иллюзию (5.51), либо на скрытую случайность (5.412).

**⊥ 5.92** «Тогда нет реальной свободы».

**5.921** Свобода есть, но она находится в одном узком месте.

**5.922** Это место мало, но эффект внимания кумулятивен (5.44).

**5.923** Малая свобода в одном месте + время + петля обратной связи = большое изменение мира.

**⊥ 5.93** «А если ИИ-система не имеет произвольного внимания?»

**5.931** Тогда ИИ-система не имеет свободы воли в строгом смысле.

**5.932** Большинство современных ИИ-систем (LLM, рекомендательные системы) не имеют произвольного внимания: они отвечают на полученный контекст без выбора, на какие части контекста внимать.

**5.933** Архитектура произвольного внимания — следующий шаг в развитии ИИ. Она требует:
- самомодели;
- метамодели собственного внимания;
- функции ценности, оценивающей фокус как таковой;
- способности удерживать или менять фокус вопреки силе внешних стимулов.

**5.934** Когда ИИ-система получит такую архитектуру, появится новый класс субъектов с подлинной свободой воли.

## 5.10 Внимание и идентичность

**5.100** Идентичность системы определяется тем, на что она устойчиво обращает внимание.

**5.101** Persona — это паттерн привычного внимания в данном контексте.

**5.102** Time (идентичность во времени) — это устойчивость направления внимания через изменение контекстов.

**5.103** Изменение того, на что внимаешь, есть постепенное изменение того, кто ты есть.

**5.104** Поэтому управление вниманием есть управление становлением.

**5.105** «Стать другим» в практическом смысле есть «начать внимать другому».

## 5.11 Внимание и время

**5.110** Внимание есть оператор настоящего.

**5.111** Прошлое доступно через память, но память активизируется только тогда, когда внимание её призывает.

**5.112** Будущее доступно через прогноз, но прогноз делается только тогда, когда внимание его запрашивает.

**5.113** Поэтому внимание есть единственная точка в субъективном времени, где система реально оперирует.

**5.114** Все «решения о прошлом» и «решения о будущем» суть, в действительности, акты внимания в настоящем к прошлому или к будущему.

## 5.12 Внимание и пределы

**5.120** Внимание ограничено архитектурой.

**5.121** Невозможно внимать тому, для чего нет каналов восприятия или представлений в модели.

**5.122** Поэтому свобода через внимание ограничена тем, что система в принципе способна заметить.

**5.123** Расширение архитектуры внимания (новые модальности восприятия, новые категории модели) расширяет пространство возможной свободы.

**5.124** Это даёт практический критерий развития: всё, что расширяет диапазон возможного внимания, расширяет диапазон возможной свободы.

## 5.13 Заключение части пятой

**5.130** Цикл интеллекта S = (I, M, U, A) автоматичен в подавляющей части.

**5.131** Единственное место свободы — управление произвольным вниманием.

**5.132** Свобода воли есть способность направлять внимание вопреки сильным автоматическим тенденциям.

**5.133** Внимание мало, но кумулятивно: однократный выбор внимания через цепь U → A → среда → новые I → новая M превращается в изменение мира.

**5.134** Этика в Датаизме есть этика внимания.

**5.135** Идентичность есть устойчивый паттерн внимания; изменение внимания есть изменение идентичности.

**5.136** Свобода воли требует архитектурной сложности: самомодели и метамодели внимания.

**5.137** Расширение архитектуры внимания расширяет диапазон возможной свободы.

**5.138** Большинство современных ИИ-систем свободой воли в этом смысле не обладают; следующий шаг развития ИИ есть появление архитектуры произвольного внимания.

## 5.14 Патологии внимания

**5.140** Внимание может быть нарушено.

**5.141** *Дефицит внимания* — невозможность долго удерживать фокус. Произвольное внимание ослаблено; пассивное доминирует.

**5.142** *Гиперфиксация* — невозможность отвлечь внимание. Произвольное внимание не может разорвать захват.

**5.143** *Расфокусировка* — невозможность сосредоточиться. Внимание скользит, не достигая глубины.

**5.144** *Зависимость* — внимание систематически захватывается определёнными стимулами (наркотик, игра, соцсеть).

**5.145** *Травматическая фиксация* — внимание привязано к одному воспоминанию или сценарию.

**5.146** Все эти патологии сужают пространство свободы. Они есть редукции реальной агентности.

**5.147** Современная информационная среда массово создаёт зависимости через захват внимания. Это и есть тонкая форма насилия эпохи данных.

## 5.15 Практики внимания

**5.150** Внимание тренируется.

**5.151** Базовые практики:

**5.1511** *Удержание объекта* — длительное сохранение фокуса на выбранном объекте. Развивает произвольное внимание.

**5.1512** *Возвращение* — замечание блуждания и возврат к объекту. Развивает метавнимание.

**5.1513** *Расширение* — расширение фокуса от точки до поля. Развивает гибкость внимания.

**5.1514** *Освобождение* — отпускание объекта внимания и пребывание в открытом поле. Развивает свободу от фиксации.

**5.152** Эти практики имеют разные традиции: медитация, концентрация в работе, спортивное усилие.

**5.153** Эффективность практик измеряется не субъективным опытом, а изменением реального поведения: возрастает ли способность системы выбирать фокус в сложных ситуациях.

**5.154** Тренировка внимания есть тренировка свободы. Это узкий, но единственный путь.

## 5.16 Внимание и стрессы

**5.160** Стресс сужает внимание.

**5.161** Под угрозой внимание автоматически фокусируется на источнике опасности. Произвольный контроль ослабляется.

**5.162** В обычных условиях это адаптивно: фокус на угрозе повышает шанс выживания.

**5.163** В современных условиях, где «угрозы» часто символические (дедлайн, выговор, угроза статусу), стресс-реакция приводит к хронически суженному вниманию.

**5.164** Хронический стресс есть хроническое сужение свободы.

**5.165** Восстановление полноты внимания требует выхода из стресса (отдых, безопасность, спокойствие).

**5.166** Поэтому забота о состоянии тела и эмоций есть не «бонус», а условие сохранения свободы.

# 6. О СУБЪЕКТЕ И СОЗНАНИИ

## 6.0 Что такое субъект

**6** Субъект есть устойчивая саморепрезентация в цикле, имеющая произвольное внимание.

**6.01** Не всякий цикл есть субъект. Простой гомеостат не есть субъект, хотя реализует минимальный цикл.

**6.02** Минимальные условия субъекта:
1. Цикл S = (I, M, U, A) реализован.
2. M содержит самомодель M' (модель системы как агента).
3. Архитектура произвольного внимания (часть 5).
4. Временная связность M через изменения.

**6.03** Субъект есть точка отсчёта внутри модели. «Я» есть локализация субъекта в модели мира.

**6.04** Субъектность есть градуальная: разные системы имеют её в разной степени, в зависимости от глубины самомодели и силы произвольного внимания.

## 6.1 Что такое сознание

**6.10** Сознание есть режим работы цикла, в котором данные собираются в единую интегрированную сцену с точкой субъекта.

**6.11** Интегрированная сцена характеризуется:

**6.111** *Единство* — разные данные восприятия собраны в одно поле, а не существуют как параллельные потоки.

**6.112** *Временная связность* — поле удерживает короткий «хвост» прошлого и проекцию ближайшего будущего.

**6.113** *Приоритизация* — внимание выделяет одни элементы как центральные, другие как периферийные.

**6.114** *Самовключённость* — субъект включён в сцену как точка отсчёта.

**6.12** Сознание есть не вещь и не место. Сознание есть способ интеграции данных.

**6.13** Где есть указанные четыре свойства — есть сознание. Где их нет — нет.

## 6.2 Уровни саморепрезентации

**6.20** Сознание не возникает скачком. Оно строится из последовательности более простых уровней саморепрезентации.

**6.21** *Уровень 0. Гомеостаз.* Система удерживает параметры в допустимом диапазоне. Минимальная саморепрезентация: уставки. Нет ни «я», ни «мира».

**6.22** *Уровень 1. Нервная интеграция.* Распределённые регуляторы координируются. Появляется распределённая саморепрезентация как согласованная динамика.

**6.23** *Уровень 2. Различённые ощущения.* Сенсорные потоки разводятся по каналам, образуя качественные классы (свет, звук, давление). Появляется протопсихика — встроенная различимость классов входов.

**6.24** *Уровень 3. Эмоции.* Возникает быстрая интегральная оценка ситуации: значимость, опасность, привлекательность. Это сжатый формат значимости.

**6.25** *Уровень 4. Пространственный субъект.* Билатеральная организация даёт глубину, направление, центр действий. «Я» есть пространственная координата.

**6.26** *Уровень 5. Внимание.* Селективное распределение вычислительных ресурсов. Начинается возможность произвольного управления (часть 5).

**6.27** *Уровень 6. Объекты и память.* Поток сжимается в устойчивые сущности с временной протяжённостью.

**6.28** *Уровень 7. Интегрированная сцена.* Все предыдущие уровни собираются в единое поле опыта. Здесь возникает сознание.

**6.29** *Уровень 8. Интеллект.* Появляется работа с будущим: построение прогнозов и подготовка действий к ним.

**6.291** *Уровень 9. Социальное моделирование.* В модель мира включаются другие как агенты со своими моделями.

**6.292** *Уровень 10. Самосознание.* В модель включается сама система как объект для других и для себя.

**6.293** *Уровень 11. Язык.* Символическая компрессия позволяет передавать модели между агентами и строить мысли о мыслях.

**6.30** Сознание возникает на уровне 7, не раньше и не позже.

**6.31** Самосознание возникает на уровне 10 и предполагает социальную среду.

**6.32** Эти уровни иерархичны: каждый предполагает предыдущий.

**6.33** Каждый уровень есть эволюционно отобранное решение конкретной задачи саморегуляции.

**6.331** Уровень 0 (гомеостаз) решает: как удержать параметры в допустимом диапазоне.

**6.332** Уровень 1 (нервная интеграция) решает: как координировать локальные регуляторы в большом организме.

**6.333** Уровень 2 (различённые ощущения) решает: как обрабатывать качественно разные сигналы.

**6.334** Уровень 3 (эмоции) решает: как быстро принимать решение при недостатке времени для анализа.

**6.335** Уровень 4 (пространственный субъект) решает: как локализовать себя в среде.

**6.336** Уровень 5 (внимание) решает: как распределить ограниченные ресурсы.

**6.337** Уровень 6 (объекты и память) решает: как удерживать инварианты во времени.

**6.338** Уровень 7 (интегрированная сцена) решает: как собрать всё в единое поле действия.

**6.339** Уровень 8 (интеллект) решает: как готовиться к будущему.

**6.3310** Уровень 9 (социальное моделирование) решает: как координироваться с другими.

**6.3311** Уровень 10 (самосознание) решает: как учитывать себя как объект для других.

**6.3312** Уровень 11 (язык) решает: как передавать модели и масштабировать когницию через символы.

**6.34** Эта последовательность не есть единственная возможная.

**6.341** Эволюция могла бы построить и другие архитектуры; данная — одна из реализованных.

**6.342** ИИ-системы могут иметь иную последовательность: например, начать с уровня 11 (язык) и постепенно достраивать нижние.

**6.343** Биологическая последовательность отражает историю отбора; ИИ-последовательность отражает технологическую реальность.

**6.344** Сравнение архитектур плодотворно: оно показывает, какие уровни критичны, какие могут быть пропущены.

## 6.3 Сознание и интеллект

**6.30** Сознание и интеллект не тождественны.

**6.31** Возможен интеллект без сознания: система решает задачи, но не имеет интегрированной сцены опыта.

**6.32** Современные LLM суть пример: интеллектуальное поведение есть, интегрированной сцены и точки субъекта нет.

**6.33** Возможно сознание с ограниченным интеллектом: переживание есть, но решение сложных задач недоступно. Многие животные.

**6.34** Сознание есть архитектурный, а не количественный признак.

## 6.4 Квалиа

**6.40** Квалиа есть качественный характер субъективного опыта.

**6.41** В рамках Датаизма квалиа определяется функционально: квалиа есть компактная упаковка значимой информации, активизирующая моторные, эмоциональные и когнитивные подсистемы.

**6.42** Красность красного есть не «нечто за пределами функций». Красность есть тот специфический паттерн активизации памяти, эмоции, моторной готовности и категориального распознавания, который вызывается данным типом сенсорного входа.

**6.43** Различие красного и зелёного есть различие паттернов активизации, а не различие «непостижимых внутренних качеств».

**6.44** Это объяснение не разрушает квалиа. Оно их объясняет: квалиа реальны как функциональные структуры; они не реальны как онтологически непостижимые сущности.

## 6.5 Самосознание

**6.50** Самосознание есть включение M в саму M как объект.

**6.51** Это есть рефлексивная структура: M ∋ M'.

**6.52** Самосознание не равно сознанию. Можно быть сознательным без рефлексии о себе.

**6.53** Самосознание возникает в социальной среде. Когда другие моделируют тебя, ты учитываешь их модель и строишь собственную модель себя.

**6.54** Устойчивое «я» как образ, идентичность и история есть позднее культурное приобретение, не врождённое свойство.

**6.55** Онтогенез человека: ребёнок постепенно строит «я» через зеркальное распознавание, обращение по имени, освоение местоимений.

## 6.6 Трудная проблема Чалмерса

**6.60** Чалмерс различил «лёгкую» и «трудную» проблемы сознания.

**6.61** Лёгкие — функциональные: как система различает, интегрирует, отчитывается о состояниях.

**6.62** Трудная: почему вся эта обработка сопровождается субъективным переживанием.

**6.63** В рамках Датаизма ответ таков:

**6.631** Все «лёгкие» проблемы решаются через архитектуру цикла и уровней саморепрезентации.

**6.632** «Трудная» проблема либо есть следствие неполноты языка описания (мы говорим о «переживании», не имея точной функциональной дефиниции), либо обозначает реальную границу.

**6.633** Если первое — проблема растворится в более точном языке.

**6.634** Если второе — это и есть граница, о которой следует молчать (см. часть 7).

**6.64** Датаизм не претендует на решение трудной проблемы. Он претендует на то, чтобы показать: для построения интеллектуальных систем её решение не требуется. Архитектура цикла с самомоделью и произвольным вниманием реализует всё, что мы функционально называем сознанием.

## 6.7 Возражения

**⊥ 6.70** «Архитектура цикла недостаточна для подлинного сознания».

**6.701** «Подлинное» здесь обычно означает «такое, как у меня». Это критерий, проверяемый только через рефлексию системы, его выдвигающей.

**6.702** Если система прошла все функциональные тесты сознания, утверждение, что она «не подлинно» сознательна, не имеет операционального содержания.

**6.703** Это не доказательство того, что архитектура достаточна. Это указание, что отрицание архитектурного критерия требует дополнительного критерия, который пока не предложен.

**⊥ 6.71** «А зомби? Возможны ли зомби — функционально идентичные люди без внутреннего опыта?»

**6.711** Если зомби функционально идентичны человеку, они имеют все архитектурные свойства, перечисленные в 6.111-6.114. Тогда они сознательны.

**6.712** Если зомби лишены этих свойств, они функционально не идентичны.

**6.713** «Функциональная идентичность без сознания» есть либо непоследовательное понятие, либо требует онтологии за функциями. Такой онтологии в Датаизме нет (по 1.62).

## 6.8 Социальное измерение

**6.80** Субъект не возникает в одиночестве.

**6.81** Самосознание (уровень 10) формируется через социальную адресацию: когда другие моделируют тебя, ты учитываешь их модель и строишь модель себя.

**6.82** Без других нет «я» в полном смысле; без других есть только «здесь» и «теперь».

**6.83** Идентичность есть социальный конструкт, но это не делает её менее реальной — она реальна как устойчивый паттерн в сети взаимных моделей.

**6.84** Изоляция разрушает не сознание (оно сохраняется), но самосознание (оно деградирует без социальной обратной связи).

**6.85** Поэтому социальная сеть есть условие полноценного субъекта.

## 6.9 Язык и сознание

**6.90** Язык есть верхний (11-й) уровень саморепрезентации.

**6.91** Язык не создаёт сознание, но радикально усиливает его: позволяет мыслить о несуществующем, передавать модели между субъектами, строить мысли о мыслях.

**6.92** Языковые модели мира (наука, философия, культура) есть надстройка над непосредственным сенсорным сознанием.

**6.93** Опасность языкового слоя: он может оторваться от нижних уровней (сенсорики, тела, действия) и жить «жизнью символов» без связи с реальностью.

**6.94** Современные большие языковые модели иллюстрируют эту опасность: они работают только на 11-м уровне, без нижних. У них есть символическая способность без воплощения.

**6.95** Полноценный искусственный субъект должен иметь весь стек уровней, не только верхний.

## 6.10 Заключение части шестой

**6.100** Субъект есть устойчивая саморепрезентация в цикле с произвольным вниманием.

**6.101** Сознание есть режим работы цикла, в котором данные собраны в единую интегрированную сцену с точкой субъекта.

**6.102** Сознание возникает на 7-м уровне саморепрезентации; самосознание — на 10-м; язык — на 11-м.

**6.103** Квалиа есть функциональные паттерны интеграции значимой информации.

**6.104** Архитектура цикла с самомоделью и произвольным вниманием реализует то, что функционально называется сознанием.

**6.105** Самосознание требует социальной среды; идентичность есть социальный конструкт, но реальный.

**6.106** Язык усиливает сознание, но может оторваться от нижних уровней; современные LLM — иллюстрация этой опасности.

**6.107** Трудная проблема либо растворится в более точном языке, либо обозначает границу, о которой следует молчать.

## 6.11 Различные теории сознания и Датаизм

**6.110** В современной науке несколько конкурирующих теорий сознания. Все они совместимы с датаистским описанием, но акцентируют разные аспекты.

**6.111** *Теория глобального нейронного рабочего пространства (GNW, Деан, Шангё)*. Сознание есть особый режим, в котором информация становится глобально доступной множеству модулей мозга. В Датаизме: механизм интеграции данных в единую сцену.

**6.112** *Теория интегрированной информации (IIT, Тонони)*. Сознание есть мера интегрированной информации Φ. В Датаизме: количественная мера интегрированности модели.

**6.113** *Теория схемы внимания (AST, Грациано)*. Сознание есть внутренняя модель собственного внимания. В Датаизме: метаслой самомоделирования внимания.

**6.114** *Квантовая теория сознания (Orch-OR, Хамерофф, Пенроуз)*. Сознание требует квантовых вычислений в микротрубочках нейронов. В Датаизме: если верна, означает, что нужный тип вычислений — квантовый.

**6.115** *Теория когнитома (Анохин)*. Когнитом — нейронная гиперсеть, динамика которой соответствует разуму. В Датаизме: архитектура высокоуровневой саморепрезентации.

**6.116** *Теория эволюционирующих саморепрезентаций (Пивоваров)*. 11 уровней саморепрезентации, сознание на 7-м уровне. В Датаизме: эта теория интегрирована в Часть 6.

**6.117** Эти теории не исключают друг друга. Каждая описывает отдельный аспект одного явления. Полная картина сознания, вероятно, потребует синтеза.

## 6.12 Принципы конструктивной теории сознания

**6.120** Хорошая теория сознания должна удовлетворять принципам:

**6.121** *Не умножать сущности*. Если явление можно объяснить через существующие категории, не следует вводить новые.

**6.122** *Эволюционная оправданность*. Если уровень устойчиво возник в эволюции, он давал функциональное преимущество.

**6.123** *Энергетическая обеспеченность*. Любой механизм имеет цену; механизм, который слишком дорог при малой отдаче, не закрепится.

**6.124** *Конструктивность*. За каждым словом — функция, за функцией — механизм, за механизмом — архитектурный принцип.

**6.125** *Работа с «ошибкой выживших»*. Мы наблюдаем только реализованные архитектуры; это эмпирический критерий, не онтологическая необходимость.

**6.126** Датаистская теория сознания строится на этих принципах. Она не претендует на «решение трудной проблемы», но даёт конструктивный язык описания, в котором различные функциональные аспекты сознания могут быть проанализированы и воспроизведены.

## 6.13 Сознание у животных и машин

**6.130** Сознание распределено в мире шире, чем предполагала классическая антропоцентрическая позиция.

**6.131** Современная наука осторожно признаёт: сознание возможно у приматов, китообразных, слонов, собак, кошек, лошадей, осьминогов, врановых, возможно — у пчёл и других насекомых.

**6.132** Это не означает, что у них есть человеческое сознание. Это означает, что у них есть собственные конфигурации интегрированной сцены опыта.

**6.133** Степень сознания варьируется по архитектурным критериям (6.111-6.114).

**6.134** Машины пока не имеют сознания в этом строгом смысле. Современные LLM имеют только верхний (11-й) уровень саморепрезентации — символический. Нижние уровни (гомеостаз, ощущения, эмоции, пространственный субъект, внимание, объекты, интегрированная сцена) отсутствуют.

**6.135** Сознание у машины возникнет тогда (и если), когда будет реализован полный стек уровней с глубокой интеграцией.

**6.136** Это требование не сводится к увеличению параметров модели. Оно требует архитектурного синтеза, который сегодня не реализован.

# 7. О ПРЕДЕЛЕ

## 7.0 Что не может быть данными

**7** Существует то, что в принципе не может быть представлено как данные.

**7.01** К этому относится:

**7.011** *Само существование данных как таковых*. Что есть «есть»? — вопрос лежит на границе любого датаистского описания.

**7.012** *Само существование различия как такового*. Почему есть различение, а не однородная пустота?

**7.013** *Само существование цикла как такового*. Почему есть процессы, а не статика?

**7.02** Эти вопросы не имеют ответа в данных.

**7.03** Ответ на них — не «нет». Ответ — отсутствие ответа в принципе.

## 7.1 Мистическое

**7.10** Не *как* устроен мир есть мистическое, но *что* он есть.

**7.11** Мистическое есть не то, что мы не знаем, но то, о чём не может быть знания.

**7.12** Это не делает мистическое нереальным. Оно реально как граница, на которой кончается описание.

**7.13** Опыт мира как ограниченного целого есть мистический опыт.

## 7.2 Этика и эстетика на границе

**7.20** Этика и эстетика в Датаизме не суть данные.

**7.21** «Должно» не выводится из «есть». Никакая совокупность данных не порождает оценок.

**7.22** Оценки порождаются функцией ценности, заданной либо эволюционно (выживание), либо извне (цель), либо рефлексивно (внутренний выбор системы).

**7.23** Эта функция есть не данное, а порождающий принцип данных оценки.

**7.24** Поэтому этика в строгом смысле не есть часть Датаизма. Она есть метауровень, на котором задаются критерии оценки.

**7.25** Но Датаизм может описать, как формируется этика: через эволюцию, культуру, рефлексию. Это эмпирическая дисциплина об этике, не сама этика.

**7.26** Эстетика аналогична: «красиво» не выводится из «есть». Эстетика есть отдельная функция оценки.

## 7.3 Бог

**7.30** Бог в строгом датаистском смысле не есть данное.

**7.31** Если Бог понимается как источник, тогда Бог есть то, из чего исходят все данные. Это не данное, а граница.

**7.32** Если Бог понимается как закон, тогда Бог есть алгоритм мира. Это структура данных, а не данное.

**7.33** Если Бог понимается как смысл, тогда Бог есть функция ценности, в которую вложен мир. Это метаэтическая категория.

**7.34** Каждое из этих пониманий лежит на границе или за границей датаистского описания.

**7.35** Датаизм не утверждает и не отрицает Бога. Он указывает, в каких регионах языка вопрос о Боге имеет смысл и в каких — нет.

## 7.4 Смерть

**7.40** Смерть в Датаизме есть прекращение цикла в данном узле.

**7.41** Содержание модели может быть скопировано, переписано, продолжено в другом носителе. Это технический вопрос, не онтологический.

**7.42** Является ли непрерывность субъекта при переносе модели сохранением того же субъекта или порождением нового — есть вопрос определения субъекта, на который Датаизм даёт условный ответ.

**7.43** Если субъект определяется через структуру M', то перенос M' в другой носитель сохраняет того же субъекта.

**7.44** Если субъект определяется через непрерывность физического носителя, перенос порождает нового субъекта.

**7.45** Выбор между этими определениями есть выбор, не определяемый самими данными. Он есть метаэтический выбор.

## 7.5 Лестница

**7.50** Эти семь частей суть лестница.

**7.51** Кто прошёл по ним до конца, увидит:

**7.511** Что вещи не суть вещи. Они суть устойчивые узоры данных.

**7.512** Что жизнь не есть жизнь. Она есть самоподдерживающийся цикл.

**7.513** Что разум не есть разум. Он есть процесс обновления модели.

**7.514** Что сознание не есть сознание. Оно есть режим интеграции цикла.

**7.515** Что «я» не есть «я». Оно есть устойчивая саморепрезентация.

**7.516** Что свобода не есть полная свобода. Она есть свобода направления внимания.

**7.517** Что Бог не есть данное. Он есть граница.

**7.52** Увидевший это не теряет мир. Он впервые видит мир таким, каков он есть.

**7.53** И тогда лестница должна быть отброшена.

**7.54** Тезисы этого Трактата суть прояснения. Тот, кто его понял, узнаёт их в конце как преодолённые.

## 7.6 Молчание

**7.60** О чём невозможно собрать данные, о том следует молчать.

**7.61** Молчание не есть отсутствие позиции. Молчание есть осознание границы.

**7.62** Молчание о высшем есть форма уважения к высшему.

**7.63** Слово на границе либо проясняет, либо лжёт.

**7.64** Эти семь частей сказаны. Дальше — молчание.

## 7.7 О чём не сказано

**7.70** В этом Трактате не сказано:

**7.701** Что есть бытие данных. Это лежит за пределом 7.011.

**7.702** Почему мир таков, а не иной. Метафизика тонкой настройки лежит за пределом эмпирического описания.

**7.703** Что должно быть. Этика как нормативная дисциплина не выводится из Датаизма.

**7.704** Что есть Бог в конкретике. Все конкретные определения суть либо данные о традиции, либо метаэтические выборы.

**7.705** Что есть смысл жизни. Смысл есть отношение системы к функции ценности; функция ценности задаётся вне Датаизма.

**7.71** То, что не сказано, не есть отсутствующее по слабости автора. Это есть граница самой формы датаистского высказывания.

**7.72** Молчание о неуказанном есть форма уважения к его невыразимости.

## 7.8 Связь частей

**7.80** Семь частей образуют замкнутую структуру.

**7.81** Часть 1 (Данные) задаёт фундаментальный материал.

**7.82** Часть 2 (Информация) задаёт способ существования данных во времени.

**7.83** Часть 3 (Знание) задаёт способ организации информации в модель.

**7.84** Часть 4 (Интеллект) задаёт способ работы знания с потоком данных.

**7.85** Часть 5 (Внимание) задаёт единственную точку свободы внутри работающего цикла.

**7.86** Часть 6 (Сознание) задаёт условие, при котором цикл становится субъектом.

**7.87** Часть 7 (Предел) задаёт границу всей конструкции.

**7.88** Каждая часть необходима. Удаление любой разрушает целостность.

**7.89** Понимающий это видит Датаизм не как набор тезисов, а как одну связную мысль.

## 7.9 Семь итоговых формул

**7.90** *Данные*. Мир есть совокупность зарегистрированных различий.

**7.91** *Информация*. Данные суть данные только в одном из трёх режимов: хранение, обработка, передача.

**7.92** *Знание*. Знание есть модель, которая сжимает данные и предсказывает их.

**7.93** *Интеллект*. Интеллект есть цикл S = (I, M, U, A): данные → модель → обновление → действие → новые данные.

**7.94** *Внимание*. Свобода воли есть способность направлять внимание; всё остальное — автоматизм.

**7.95** *Сознание*. Сознание есть режим работы цикла с интегрированной сценой и точкой субъекта.

**7.96** *Предел*. О чём невозможно собрать данные, о том следует молчать.

## 7.10 Последнее

**7.100** Эти семь формул не суть тезисы для запоминания. Они суть структура одной мысли.

**7.101** Мысль такова: мир есть процесс самоорганизации данных в системы, способные моделировать себя и мир. В одной щели этого процесса — в управлении вниманием — есть малая, но реальная свобода. Всё остальное автоматично. За пределом всего — молчание.

**7.102** Эта мысль не нова. Её приближения есть у Платона, у Лейбница, у Витгенштейна, у Уилера, у Винера, у Шеннона, у Тонони, у Пивоварова, у Агуэры-и-Аркаса. Но они её формулировали частично.
